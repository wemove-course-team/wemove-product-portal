# ADR 0001 课程核心与长期架构分期

状态：规划提案，随规划PR评审；用户已确认2–3天约束及lizhikeer前端分配。日期：2026-09-05。

## 背景

已有Vue3与MySQL演示SQL，未有后端。选题要求真实用户、新闻/产品及后台；重构规格覆盖完整商业网站。七人只有2–3天，不适合同时换前端/数据库和建立交易系统。

## 决策

课程延续Vue/Vite和MySQL，以NestJS/TypeScript模块化单体建立真实核心。公共前端和最终UI由lizhikeer负责，后端骨架与鉴权交cy0207kaw，数据库与产品交Snowed-night。其他领域按完整前后台闭环划分。

课程暂不引入SSR、Redis、消息队列、微服务、通用CMS搭建器和复杂RBAC；关闭正式流程中的模拟交易。M4再做Nuxt、完整经销商、媒体和上线安全，M5逐步加入国际化与交易。

## 代价及替代方案

Vue SPA暂不能满足长期SEO/首屏HTML要求，所以课程版不宣称商业上线就绪。立即Nuxt会增加迁移成本，Next/PostgreSQL全重建复用率低，微服务缺乏必要性。后端语言原资料不限制，NestJS是规划者根据现有JS栈作出的推荐；如团队首日确认已有熟悉的后端骨架可显著缩短交付，可在B00更新本ADR并同步所有契约/Issue，不能各领域自行选语言。

## 验证与再评估

首日下午完成“后台写入→数据库→公开读取”闭环，否则集中修复平台，不扩大范围。第2天中午检查核心完成度，必要时取消P1。商业化前用Nuxt单页试点验证SEO/缓存/身份边界；扩容和外部集成均以实际测量和业务需求启动。
